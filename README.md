# mapas-prot-civi

Aplicación React Native (Expo) para consultar el control de protección civil del CUCS:
equipos de seguridad por edificio (extintores, botiquines, salidas de emergencia, puntos de reunión)
y su estado de revisión. Toca un elemento para alternar entre Vigente y Pendiente.

## Uso

```
npm install
npm start
```
